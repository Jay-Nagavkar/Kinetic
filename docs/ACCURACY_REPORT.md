# KhelSetu: Accuracy & Computer Vision Benchmark Report

---

## 1. Methodology & Metric Definitions

To ensure scientific honesty without fabricating accuracy claims, KhelSetu evaluates repetition counting and hold durations against ground-truth human annotations using two primary metrics:

1. **Mean Absolute Error (MAE)**:
   $$\text{MAE} = \frac{1}{N} \sum_{i=1}^{N} |C_{\text{predicted}, i} - C_{\text{ground\_truth}, i}|$$
2. **Off-by-One Accuracy ($\text{Acc}_{\pm 1}$)**:
   $$\text{Acc}_{\pm 1} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}(|C_{\text{predicted}, i} - C_{\text{ground\_truth}, i}| \le 1) \times 100\%$$
3. **Rejection Precision ($P_{\text{reject}}$)**:
   $$\text{Precision} = \frac{\text{True Form Violations Detected}}{\text{Total Form Violations Tagged}} \times 100\%$$

All metrics are computed directly by running `scripts/eval_reps.mjs` against landmark time-series traces.

## 3. EMA vs. One-Euro Filter Comparison

* **EMA (Exponential Moving Average)**:
  - *Advantage*: Very simple arithmetic; zero memory footprint.
  - *Disadvantage*: Fixed $\alpha$ creates a trade-off: high smoothing lags behind rapid inflection points, while low smoothing permits high-frequency landmark jitter to trigger spurious reps.
* **One-Euro Filter (Casiez et al. 2012)**:
  - *Advantage*: Dynamically scales cutoff frequency based on movement velocity. Eliminates jitter while standing still without introducing lag during rapid descents.
  - *Result*: Retained as the recommended filter for high-tempo exercise sessions.

## 4. Known Failure Cases & Mitigations

| Failure Mode | Trigger Condition | Engine Behavior | UI Feedback & Mitigation |
| :--- | :--- | :--- | :--- |
| **Shallow Squat** | Knee angle does not cross $105^\circ$ | State machine remains in `up` phase; rep is not incremented. | Visual skeleton turns orange; prompt shows "Stand tall to begin". |
| **Hip Sag in Push-up** | Shoulder-Hip-Ankle angle $< 160^\circ$ | Rep discarded at top extension; flagged as `hips_sagging`. | Audio buzz tone plays; UI warns "Keep your body in a straight line". |
| **Extreme Low Light** | Ambient lighting $< 30$ lux | Landmark visibility $< 0.5$; integrity gate marks session `invalid`. | Pre-test framing check alerts "Need more light in the room". |
| **Multiple People in Frame** | Roommate walks into camera view | Multi-person frame ratio $> 10\%$; integrity gate marks session `invalid`. | Rejects session with reason "More than one person was in view". |
